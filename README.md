# Ohkajhu FreshFlow

Farm-to-branch planning prototype (sample data). A single-file web app: supply vs demand, branch allocation, POS sales forecast, waste tracking, and a farmer kiosk.

## Run locally

Open `index.html` in any browser. No build step or dependencies.

## Deploy with GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Notes

- All data is sample data and is stored in the browser's `localStorage`.
- The page loads the Inter font from Google Fonts; it falls back to the system font if offline.
